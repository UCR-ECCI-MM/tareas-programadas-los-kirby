# Primer avance

1. (10%) Este primer avance debe incluir:

- Documento pdf con especificación de la funcionalidad de la aplicación y con la
  explicación de las estructuras de datos específicas que requerirá el programa
  para almacenar la información a partir del archivo de entrada.

- Una aplicación prototipo básica con GUI, en Python, con un menú con las
  opciones para la funcionalidad definida. Una de las opciones debe mostrar otra
  ventana con algún tipo de gráfico (barras, pie, etc) que muestre datos
  inventados. El objetivo es ir conociendo las herramientas de Python.

## Manual de Uso

Para poder ejecutar el prototipo GUI de la aplicación es necesario instalar las
siguientes bibliotecas de Python:

- Tkinter (biblioteca estándar de Python)

      sudo apt-get install python3-tk

- Pillow (PIL)

      pip install pillow

- NumPy

      pip install numpy

- Matplotlib

      pip install matplotlib

Para ejecutar, en consola escriba el siguiente comando:

      python3 prototype.py
