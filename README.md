# Tareas programadas CI0124 - Computabilidad y Complejidad, Grupo 01

## Tarea programada 1: Descripción

Se dispone de un archivo tipo XML (tomado de MedlinePlus.gov) con información
médica relevante para pacientes. Se debe procesar el archivo
mediante un analizador léxico (lexer) y un analizador sintáctico (parser) para mostrar
los datos a los usuarios de una manera legible y agradable.

La aplicación debe tener diferentes funcionalidades las cuales le permiten al
usuario obtener y visualizar diversa información de diferentes formas.

Los requisitos de la aplicación son:

1. Debe tener al menos tres opciones (funcionalidades) para el usuario.
2. Las funciones de su programa deben utilizar la mayor cantidad de datos del
archivo.
3. En la pantalla principal debe mostrarse la información general del dataset:
cantidad de registros, fecha y hora de los datos.
4. Debe tener una interfaz gráfica de usuario (GUI) amigable y de fácil uso.
5. Su programa debe mostrar al menos un gráfico de datos.
6. Debe incorporar en alguna opción el poder dirigirse a páginas web que estén dentro
de los datos de entrada.
7. Debe tener la mayor robustez posible en la validación de los datos de entrada.

## Tarea programada 2: Descripción

Cada grupo debe proponer un problema que no se puede resolver en tiempo
polinomial, o sea de tipo NP-Duro o NP-Completo, para ser resuelto mediante
tres técnicas:

1. Fuerza bruta
2. Una heurística específica para el tipo de problema a resolver
3. Una metaheurística de las vistas en el curso

Esta tarea consiste en solucionar el problema mediante las tres técnicas y en
analizar y comparar los resultados obtenidos en términos de eficacia
(cumplimiento del objetivo del programa) y eficiencia (tiempo, espacio, etc).

Cada grupo deberá realizar una exposición formal de su trabajo la cual debe
incluir:

1. Presentación del problema a resolver y su importancia
2. Explicación de las tres técnicas aplicadas a la solución, incluyendo
   conceptos teóricos y particularidades de la implementación
3. Ejecución del programa
4. Presentación de los resultados de las técnicas desarrolladas y su comparación
5. Conclusiones
